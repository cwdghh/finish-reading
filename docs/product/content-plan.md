# 文本库与内容计划

状态：候选清单，待逐篇核对与录入  
更新：2026-11-07

## 原则

- 以中国公版为底线：作者逝世超过 50 年；优先中国 + 美国双公版（1929 年前发表），也允许标注后的仅中国公版文本。
- 不做“整本书阅读”，做 **2–15 分钟、能独立读完的阅读单元**。
- 体裁均衡：诗/词、散文、小说、古文都要有。
- 情绪覆盖：安慰、陪伴、逗笑、点醒、美、逃离、力量；避免全部偏沉重。
- 每个单元都要有：一句推荐理由、一个“阅读天气”、内容提示、来源与许可。
- 不收录需要复杂注释才能读懂的文本；古诗文只加 2–3 条原创/公版短注。

## 阅读单元

“单元”是产品匹配、阅读和读完卡片的基本对象。结果卡显示“作品名 · 单元名”，例如“《背影》· 车站买橘”。

| 体裁 | 切分方式 | 长度 | 备注 |
| --- | --- | --- | --- |
| 诗/词 | 整首 | 2–5 分钟 | 不节选，保持完整 |
| 散文 | 一个完整场景/段落 | 5–10 分钟 | 附一句前情，保证独立成立 |
| 小说 | 一个能独立理解的场景 | 8–15 分钟 | 附一句前情；不制造悬崖式结尾 |
| 古文 | 一则短文/段落 | 4–10 分钟 | 附 2–3 条短注；不做全文翻译 |

单元规则：

- 必须有开头、结尾和独立的情绪弧线；不能只是“随机截一段”。
- 不要求用户读完整本书；读完一个单元就是一次完整的产品体验。
- 长作品在卡片上明确标注“节选”，并显示单元名，避免误解。
- 每个单元附 `contextBefore`（一句前情），必要时附 `contextAfter`（一句收束）。
- 注释与前言自己写，不复制现代出版社的注释/翻译。

## 版权规则

- 中国：作者逝世超过 50 年；2026 年以 1975 年及以前逝世为安全线。
- 美国：优先 1929 年前发表；不是硬性要求。仅中国公版可以收录，但必须标注 `public-domain-cn`，并在“文本来源”页说明适用法域。
- 本批 18 个单元全部为双公版；后续可加入仅中国公版的补充单元。
- 无法确认中国公版状态的不收录。
- 不使用现代校注本、白话翻译、导读、赏析（可能仍有版权）。
- 每个单元记录：作者、逝世年份、首次发表年份、来源、许可、核对日期、版权范围。
- 公版来源与核验流程见 [public-domain-sources.md](public-domain-sources.md)。

## 单元示例

- 《背影》· 车站买橘  
  `contextBefore`: 那年冬天，祖母去世，父亲在车站送我。  
  选段：父亲穿过铁道去买橘子的段落；读到父亲背影消失在人群里。
- 《故乡》· 少年闰土  
  `contextBefore`: 我回到阔别二十余年的故乡，母亲提起了闰土。  
  选段：少年闰土讲雪地捕鸟、海边西瓜的段落；不进入中年闰土的沉重部分。
- 《社戏》· 月夜行船  
  `contextBefore`: 我们在平桥村，终于等到去赵庄看戏的晚上。  
  选段：月夜行船、豆麦清香、远处戏台的段落。
- 《祝福》· 祥林嫂片段  
  `contextBefore`: 鲁镇的人们又要在祝福声中过年了。  
  选段：祥林嫂在祝福时问“人死后有没有魂灵”的段落；需要内容提示。
- 《咏雪》  
  全文；`contextBefore`: 谢太傅在一个寒雪天把家人聚在一起。

## 来源策略

1. 诗词：`chinese-poetry` 初筛 → 中文维基文库/扫描件核对。
2. 近现代公版：中文维基文库带公版模板的页面 → 逐篇核对作者逝世年/发表年。
3. 古典散文/小说：中文维基文库或 Project Gutenberg → 国家图书馆/Internet Archive 影像核对。
4. ctext.org 只做检索核对，不批量复制。
5. 注释和“读前一句”自己写，不复制现代出版社的注释/翻译。
6. 站点增加“文本来源”页/弹窗，列出作品、来源、许可和核对日期。
