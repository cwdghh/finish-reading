# 文本库与内容计划

状态：v2 已入库 53 个单元，`npm run build` 内的文本校验通过

更新：2026-11-08

## 原则

- 以中国公版为底线：作者逝世超过 50 年；本批全部为中国 + 美国双公版。
- 不做“整本书阅读”，做 **2–15 分钟、能独立读完的阅读单元**。
- 体裁均衡：诗/词、散文、小说、古文都要有；避免同一作者、同一体裁连续堆叠。
- 情绪覆盖：安慰、陪伴、逗笑、点醒、美、逃离、力量；避免全部偏沉重。
- 每个单元都要有：一句推荐理由、一个“阅读天气”、内容提示、来源与许可、核对日期。
- 不收录需要复杂注释才能读懂的文本；古诗文只加 2–3 条原创短注。
- 不为数量降低版权或文本质量；宁缺毋滥。

## 阅读单元

“单元”是产品匹配、阅读和读完卡片的基本对象。结果卡和完成卡以作品名为主标题，单元名作为副标题，`全文 / 节选 / 整首` 以标签呈现。

| 体裁 | 切分方式 | 长度 | 备注 |
| --- | --- | --- | --- |
| 诗/词 | 整首 | 2–5 分钟 | 不节选，保持完整 |
| 散文 | 一个完整场景/段落 | 4–10 分钟 | 附一句前情，保证独立成立 |
| 小说 | 一个能独立理解的场景 | 6–15 分钟 | 附一句前情；不制造悬崖式结尾 |
| 古文 | 一则短文/段落 | 2–8 分钟 | 附 2–3 条短注；不做全文翻译 |

单元规则：

- 必须有开头、结尾和独立的情绪弧线；不能只是“随机截一段”。
- 不要求用户读完整本书；读完一个单元就是一次完整的产品体验。
- 长作品在卡片上明确标注“节选”，并显示单元名，避免误解。
- 每个单元附 `contextBefore`（一句前情），必要时附 `contextAfter`（一句收束）。
- 注释与前言自己写，不复制现代出版社的注释/翻译。

## 版权规则

- 中国：作者逝世超过 50 年；2026 年以 1975 年及以前逝世为安全线。
- 美国：2026 年 1930 年及以前发表的作品已进入公有领域；本批全部满足双公版。
- 本批 53 个单元全部为 `public-domain-cn-us`，来源均为中文维基文库；未使用 ctext.org 文本。
- 无法确认中国公版状态的不收录。
- 不使用现代校注本、白话翻译、导读、赏析（可能仍有版权）。
- 每个单元记录：作者、逝世年份、首次发表年份、来源、许可、核对日期、版权范围、内容提示、预置摘句。
- 公版来源与核验流程见 [public-domain-sources.md](public-domain-sources.md)。

## 内容库路线

| 阶段 | 目标数量 | 说明 |
| --- | --- | --- |
| 概念验证 | 18 | 已留在库中，验证闭环 |
| 首次公开版 | 48–60 | 当前 53 个，已满足；默认 9 个之外仍有充足可换内容 |
| 后续扩充 | 100+ | 按批次补充，保持版权与文本质量 |

扩充优先级：

1. 古典诗词与古文：公版清晰、来源稳定、短单元多。
2. 1920 年代双公版现代散文/小说/诗：鲁迅、朱自清、郁达夫、徐志摩、闻一多、戴望舒、许地山、庐隐等。
3. 后续如加入仅中国公版文本，必须标注 `public-domain-cn` 并在来源页说明适用法域；本批未使用。

入库流程：候选 → 版权核验 → 文本核对 → 单元切分 → 情绪/需求标签 → 预置摘句 → 移动端试读 → 入库。

## 自动校验

`site/scripts/validate-texts.mjs` 在 `npm run build` 前运行，检查：

- 必填字段、唯一 ID、四位体裁。
- 作者逝世年份 ≤ 1975、发表年份 ≤ 1930、来源为中文维基文库、无 ctext.org。
- 许可、核对日期、版权范围、内容提示、上下文。
- 预置摘句必须是正文规范化后的子串；节选必须带内容提示。
- 2–15 分钟阅读时长、难度/节奏/密度/天气/效价/唤醒度。
- 分段/诗行长度、注释、`whyItFits` 与 `moodDescription` 长度。
- 文本库总数 48–60、各体裁 ≥ 6、各需求 ≥ 8、各叶节点 ≥ 8、优先叶节点 × 需求 ≥ 3。

## 来源策略

1. 诗词：`chinese-poetry` 初筛 → 中文维基文库核对。
2. 近现代公版：中文维基文库带公版模板的页面 → 逐篇核对作者逝世年/发表年。
3. 古典散文/小说：中文维基文库 → 国家图书馆/Internet Archive 影像核对。
4. ctext.org 只做检索核对，不批量复制。
5. 注释和“读前一句”自己写，不复制现代出版社的注释/翻译。
6. 站点“文本来源”抽屉列出作品、来源、许可和核对日期。
