# MVP 范围与实施计划（v2）

状态：v2 本地实现与验收通过；公网部署与论坛帖暂停，等待用户确认

更新：2026-11-08

## MVP 目标

用 60 个中国双公版阅读单元，做出一个完整、可公网演示的“心情 → 配文 → 选文 → 读完 → 卡片”闭环。不登录、不依赖外部 API、不做 AI 摘要。v2 重点解决 v1 的签到过长、结果重复、文本量不足与移动端操作成本。

## 页面与流程

1. **首页即签到**：不做营销封面；桌面左侧保留缩小的“读完”字标与实时处方签，移动端压缩品牌区，首屏完整露出 3 张心境卡 + “说不清”跳过卡。
2. **四步顺序签到**：
   - 01 此刻：低落 / 疲惫 / 还不错，3 张分支卡；附“说不清”跳过，也可直接写一句话开始。
   - 02 更具体：按 01 分支动态列出叶节点。低落〔心里有点堵 / 想逃开一会儿 / 有点委屈〕；疲惫〔累但不想睡 / 需要一点力气 / 脑子停不下来〕；还不错〔今天还不错 / 想轻松一点〕。可跳过。
   - 03 想要：按分支重排 4 个主选项，其余 2 个放进“更多选择”。低落〔被安慰 / 被陪着 / 被点醒 / 都行〕；疲惫〔被安慰 / 被逗笑 / 被点醒 / 都行〕；还不错〔被逗笑 / 想看美的东西 / 被点醒 / 都行〕。
   - 04 时间：5 / 15 / 25 分钟 + 诗 / 散文 / 小说 / 古文 / 随便，合并为一页；唯一主按钮“生成处方”；可选内容偏好收在“更多偏好”。
   - 选择分支、叶节点、需求后 **280ms** 自动推进；保留“上一步”；切换后焦点移到新问题 H1，并用 `aria-live` 播报步骤。
3. **自由输入独立入口**：Q1“或者直接说一句”，最多 80 字；可一句话直接开始，不需要先选心境。用本地关键词词典给出可修改的心情建议，例如“今天有点累，脑子停不下来”→ 建议“累但不想睡 / 脑子停不下来”，主题“疲惫 / 夜 / 脑子停不下来”。无 AI、无外部 API。未选心境时使用中性权重，结果页明确写“未选状态 · 按你写的话来配”。
4. **配文结果**：默认 9 个（8–10 个范围内），一个主卡 + 紧凑列表；主标题为作品名，`全文 / 节选 / 整首` 作为标签；匹配详情折叠。头部提供“调整条件”（回到第 04 步）和真正的“换一批”（排除当前批次并生成下一批），两者分开。
5. **阅读**：默认连续滚动，散文、小说、古文的全部段落一次展开；诗歌默认整首，可切换逐句。默认开启“聚焦当前段/句”：当前段落清晰、其余段落降低不透明度，可在设置关闭。末尾只有一个“我读完了”，不再逐段点击翻页；可写一句可选笔记；退出提示不保存进度。
6. **读完卡片**：读后心情初始为空，必须显式选择；选 1–3 枚印章；可换摘句、写一句笔记；竖版 4:5 PNG；移动端固定底部“收下卡片 / 下载 PNG”，并说明下载会同时存入处方笺。卡片主标题为作品名，副标题为单元名，`全文 / 节选 / 整首` 作为标签。
7. **本地处方笺**：保存已读单元、笔记、读后心情、摘句、印章；导航按钮的 `aria-label` 为“处方笺，查看读过的卡片”；历史卡以作品名为主标题。
8. **文本来源**：抽屉列出每个单元的作品、作者、发表年、来源、许可、核对日期。

## 阅读单元

- 匹配、阅读和读完卡片的对象都是“单元”，不是整本书。
- 诗/词整首；散文一个完整场景/段落；小说一个能独立理解的场景；古文一则短文/段落。
- 每个单元 2–15 分钟，附一句 `contextBefore` 前情；长作品标“节选”。
- 当前 60 个：诗/词 27、现代散文 12、小说 7、古文 14。

## 匹配规则（可解释，不做 AI）

输入信号：

- 心境叶节点 → `moodTags`、`valence`、`arousal`。
- 需求 → `needTags`。
- 时间 → `readingMinutes`；超出可用时间的单元仍可出现，但排后并标“稍长”。
- 体裁 → `form` 作为偏好权重，不做硬筛选。
- 自由输入 → 本地关键词词典 + 与 `moodDescription` 的字二元组相似度；最多 5 篇带“因你写的话”，并说明哪些主题影响了排序。
- 内容提示 → 用户可排除敏感内容，硬过滤。

权重：

- 有心境：需求 0.25、心境 0.20、自由输入 0.15、时间 0.15、体裁 0.10、效价/唤醒 0.10、难度 0.05。
- 无心境（跳过或只写一句话）：需求 0.18、心境 0.05、自由输入 0.36、时间 0.15、体裁 0.10、效价/唤醒 0.05、难度 0.11。

输出与排序：

- 9 个结果；主卡 1 个 + 紧凑列表 8 个。
- 标签按分数阈值：`很合 ≥ 0.82`、`挺合 ≥ 0.70`、`可以看看 < 0.70`；与弱匹配线一致，不按名次固定贴标签。
- 顶级分 < 0.70 时进入弱匹配：标题“今天先读一篇”，提示可调整条件。
- 前 3 个为稳定锚点；其余只在分数相差 < 0.04 的档内做种子抽样，并按作者/体裁重复降权。
- 理由 1–2 句：一个主要维度 + 该单元独有的 `whyItFits`，避免所有卡片同一开头。

## 新鲜度与本地记录

- 日期种子：`hash(date + branch + leaf + need + time + form + free input)`；同一天、同答案稳定。
- 当天首次生成写入 `duwan:batch:v1`；重进结果页优先复用，保证稳定。
- 最近展示记录 `duwan:shown:v1`，保留 7 天（最多 300 条）；未命中缓存时优先排除。
- 最近读过（`duwan:history:v1`）继续排除；候选不足时回退并说明。
- “换一批”使用 session nonce + batchIndex 生成新种子，并排除当前 9 个；同一天也可换，但不会退化成无限随机流。

## 读完卡片

- 必含：日期、作品名、单元名、作者、阅读时长、读前心情、读后心情、一句话笔记、原文摘句、1–3 枚预设计印章。
- 读后心情：更松了 / 差不多 / 更沉了，初始不选中；不做心理评估。
- 摘句：每篇预置一句，可从正文替换。
- 印章：12 枚预设计朱红印章（情绪 6 + 状态 4 + 内容 2），不做手写签名。
- 导出：1080×1350（4:5）PNG；下载时自动存入本地处方笺。
- 本地保存：`localStorage`；不上传。

## 技术与数据

- 前端：Vite 8 + React 19 + TypeScript；原生 CSS + `--site-*` 变量。
- 路由：单页视图状态机（checkin / results / reading / finish / history）。
- 数据与逻辑：`site/src/data/texts.json`、`site/src/data/moods.ts`、`site/src/lib/freeInput.ts`、`site/src/lib/match.ts`、`site/src/lib/storage.ts`。
- 文本校验：`site/scripts/validate-texts.mjs`，已接入 `npm run build`。
- 无后端、无账号、无外部 API；文本只在浏览器处理。
- 部署：Qoder Sites 静态站点，`webDirectory: "dist"`、`spa: false`；v2 尚未重新部署。
- 兼容：Chrome / Safari / Edge 最近两个大版本；移动端 375px 起。
