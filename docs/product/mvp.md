# MVP 范围与实施计划

状态：已实现，本地与公网验收通过

更新：2026-11-07

## MVP 目标

用 18 个公共版权阅读单元，做出一个完整、可公网演示的“心情 → 配文 → 选文 → 读完 → 卡片”闭环。不登录、不依赖外部 API、不做 AI 摘要。

## 页面与流程

1. **首页即心情签到**：标题/一句话 + 6 张情绪卡；不做单独封面。
2. **心情签到**（3 步）：
   - 此刻的状态：6 张情绪卡（累但不想睡 / 心里有点堵 / 想逃开一会儿 / 需要一点力气 / 今天还不错 / 说不清）。
   - 想要的感觉：6 张需求卡（被安慰 / 被逗笑 / 被点醒 / 被陪着 / 想看美的东西 / 都行）。
   - 时间与体裁：5 / 15 / 25 分钟（25 分钟可读一个长单元或两个短单元）；诗 / 散文 / 小说 / 古文 / 随便。这两项是偏好，不是硬筛选。
   - 可选：一句话补充（最多 60 字）。
3. **配文结果**：10+ 个阅读单元，按综合匹配度降序。前 3 个标为“最匹配”，其余为“更多可读”；默认展示前 10 个，可展开更多。每张卡片含作品名、单元名、作者、体裁、时长、匹配标签（很合/挺合/可以看看）、阅读天气、推荐理由、1–2 句试读；超出可用时间的单元标“稍长”。匹配详情里可看相对分数。支持“重新匹配”。
4. **阅读**：
   - 诗歌：逐句/整首切换，读前一句上下文，读完按钮。
   - 散文/小说：按难度切成 3–5 个检查点；段末可选写一句“这段在讲什么”，也可直接继续。
   - 古文：原文 + 2–3 条简短注释；不做全文翻译。
   - 通用：进度环、计时、字号/行距/纸色/夜间模式。
5. **读完卡片**：日期、作品名、单元名、作者、时长、读前/读后心情、一句话笔记、原文摘句（每篇预置一句，可替换）、1–3 枚预设计印章；竖版 4:5 PNG 下载；存入本地“处方笺”。
6. **本地历史**：保存已读单元、笔记、偏好；重新匹配时排除最近读过的。
7. **文本来源**：页脚/弹窗列出每个单元的来源、许可与核对日期。

## 阅读单元

- 匹配、阅读和读完卡片的对象都是“单元”，不是整本书。
- 诗/词：整首；散文：一个完整场景/段落；小说：一个能独立理解的场景；古文：一则短文/段落。
- 每个单元 2–15 分钟，附一句 `contextBefore` 前情；长作品显示“节选”。
- 结果卡显示“作品名 · 单元名”，例如“《背影》· 车站买橘”。

## 阅读印章

- 不做网页手写签名；印章是预设计的 SVG/CSS 样式，直接选择。
- 共 12 枚，统一朱红：情绪 6（被安慰 / 被点醒 / 想笑 / 想哭 / 平静 / 有力量）、状态 4（夜读 / 慢读 / 读完 / 想再读）、内容 2（好句子 / 想记住）。
- 读完时选 1–3 枚，盖在读完卡片上；可随机轻微旋转，模拟盖章，但不接受手写。

## 匹配规则（可解释，不做 AI）

输入信号：

- 状态卡 → `moodTags`、`valence`、`arousal`。
- 需求卡 → `needTags`。
- 时间 → `readingMinutes` 作为时间匹配权重；超出可用时间的单元仍可出现，但排后并标“稍长”。
- 体裁 → `form` 作为偏好权重；选“诗”时诗歌优先，但其他体裁仍可出现在列表里。
- 自由输入 → 关键词词典 + 与每个单元 `moodDescription` 的字二元组余弦相似度。
- 内容提示 → 用户可排除敏感内容；这是硬过滤。

排序（建议权重）：

- 需求匹配 0.25
- 情绪匹配 0.20
- 自由输入相似度 0.15
- 时间匹配 0.15
- 体裁偏好 0.10
- 效价/唤醒度接近 0.10
- 难度匹配 0.05
- 多样性加分：不同体裁、不同作者；避免连续同一作者。

输出：

- 返回所有通过内容过滤的单元（至少 10 个；不足时显示全部并说明）。
- 按综合分降序；卡片显示“很合 / 挺合 / 可以看看”，相对分数放在匹配详情里（仅用于排序展示，不代表精确概率）。
- 前 3 个标“最匹配”，其余为“更多可读”；默认展示前 10 个，可展开。
- 重新匹配时排除最近读过的单元；不提供“换一批”这种无限刷新。

## 阅读模式

- 诗歌：单列排版，逐句显现；不设检查点，读完即卡片。
- 散文/小说：检查点按段落和难度切分；每段 300–800 字；提示语只问一个问题，笔记可选。
- 古文：原文 + 简短注释；注释可开关；不做逐句翻译。
- 通用：一次只呈现一段/一首，避免无限滚动；退出时明确提示本次进度不会保存（MVP 不做断点续读）。

## 读完卡片

- 必含：日期、作品名、单元名、作者、阅读时长、读前心情、读后心情、一句话笔记、原文摘句、1–3 枚预设计印章。
- 读后心情：3 个选项（更松了 / 差不多 / 更沉了），不做心理评估。
- 摘句：每篇预置一句，用户可在读完前从正文替换。
- 印章：从 12 枚预设计朱红印章中选 1–3 枚；不做手写签名。
- 导出：竖版 4:5 PNG；分享文案可复制。
- 本地保存：`localStorage`；不上传。

## 技术与数据

- 前端：Vite + React + TypeScript；优先原生 CSS + `--site-*` 变量，若 starter 自带 Tailwind 则只做布局辅助。
- 路由：MVP 当前倾向单页视图状态机，不引入前端路由；`prepare_site` 可先用 `spa: false`。若后续需要分享具体结果页，再改用路由并设 `spa: true`。
- 数据：`site/src/data/texts.json`、`site/src/data/moods.json`；匹配逻辑 `site/src/lib/match.ts`；文本分析 `site/src/lib/textStats.ts`。
- 无后端；无账号；无外部 API；文本只在浏览器处理。
- 部署：Qoder Sites 静态站点，公开访问；仓库格式见 [site-format.md](site-format.md)。
- 兼容：Chrome / Safari / Edge 最近两个大版本；移动端 375px 起。

## 验收标准

- [ ] 新用户从首页到读完卡片 ≤ 5 步，演示用 5 分钟文本可在 3 分钟内走完。
- [ ] 结果页至少 10 个单元（不足时显示全部并说明），按匹配度降序；前 3 个突出；每个有可理解的理由。
- [ ] 重新匹配可用，排序稳定；最近读过的单元不会重复出现。
- [ ] 手机 375px 与桌面 1440px 无横向滚动；正文行宽舒适。
- [ ] 读完卡片可下载竖版 4:5 PNG，包含读后心情、1–3 枚预设计印章和可替换摘句；刷新后本地历史仍在。
- [ ] 段落笔记可选，不写也能继续；不会出现强制填写的阻断。
- [ ] 无登录、无文本上传、无外部 API 依赖。
- [ ] 公网链接在无痕窗口可打开；无控制台报错。
- [ ] 18 个阅读单元均记录版权出处；敏感内容有提示；站点有“文本来源”入口。
- [ ] 键盘可操作；对比度达标；尊重 `prefers-reduced-motion`。
