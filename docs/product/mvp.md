# MVP 范围与实施计划

状态：待确认  
更新：2026-11-07

## MVP 目标

用 18 个公共版权阅读单元，做出一个完整、可公网演示的“心情 → 配文 → 选文 → 读完 → 卡片”闭环。不登录、不依赖外部 API、不做 AI 摘要。

## 页面与流程

1. **首页**：一句话主张 + “开始”按钮 + 一个今日单元。
2. **心情签到**（3 步）：
   - 此刻的状态：6 张情绪卡（累但不想睡 / 心里有点堵 / 想逃开一会儿 / 需要一点力气 / 今天还不错 / 说不清）。
   - 想要的感觉：5 张需求卡（被安慰 / 被逗笑 / 被点醒 / 被陪着 / 想看美的东西）。
   - 时间与体裁：5 / 15 / 25 分钟（25 分钟可读一个长单元或两个短单元）；诗 / 散文 / 小说 / 古文 / 随便。
   - 可选：一句话补充（最多 60 字）。
3. **配文结果**：3 个阅读单元卡片；每张含作品名、单元名、作者、时长、阅读天气、推荐理由、1–2 句试读；支持“换一批”和“为什么是这篇”。
4. **阅读**：
   - 诗歌：逐句/整首切换，读前一句上下文，读完按钮。
   - 散文/小说：按难度切成 3–5 个检查点；每段结束写一句“这段在讲什么”。
   - 古文：原文 + 2–3 条简短注释；不做全文翻译。
   - 通用：进度环、计时、字号/行距/纸色/夜间模式。
5. **读完卡片**：日期、作品名、单元名、作者、时长、读前/读后心情、一句话笔记、原文摘句；下载 PNG；存入本地“处方笺”。
6. **本地历史**：保存已读单元、笔记、偏好；用于“换一批”去重。
7. **文本来源**：页脚/弹窗列出每个单元的来源、许可与核对日期。

## 阅读单元

- 匹配、阅读和读完卡片的对象都是“单元”，不是整本书。
- 诗/词：整首；散文：一个完整场景/段落；小说：一个能独立理解的场景；古文：一则短文/段落。
- 每个单元 2–15 分钟，附一句 `contextBefore` 前情；长作品显示“节选”。
- 结果卡显示“作品名 · 单元名”，例如“《背影》· 车站买橘”。

## 匹配规则（可解释，不做 AI）

输入信号：

- 状态卡 → `moodTags`、`valence`、`arousal`。
- 需求卡 → `needTags`。
- 时间 → `readingMinutes` 硬过滤。
- 体裁 → `form` 硬过滤（选“随便”则不过滤）。
- 自由输入 → 关键词词典 + 与每个单元 `moodDescription` 的字二元组余弦相似度。

排序（建议权重）：

- 需求匹配 0.30
- 情绪匹配 0.25
- 自由输入相似度 0.15
- 效价/唤醒度接近 0.10
- 时间匹配 0.10
- 难度匹配 0.10
- 多样性加分：至少 2 种体裁、不同作者。

输出：

- 3 个单元；每个给出推荐理由（引用用户选中的词 + 文本特征）。
- “换一批”排除当前 3 个和本地已读。
- 无结果时放宽体裁/时间 2 分钟，并说明“为你放宽了一点条件”。

## 阅读模式

- 诗歌：单列排版，逐句显现；不设检查点，读完即卡片。
- 散文/小说：检查点按段落和难度切分；每段 300–800 字；提示语只问一个问题。
- 古文：原文 + 简短注释；注释可开关；不做逐句翻译。
- 通用：一次只呈现一段/一首，避免无限滚动；退出时确认是否保留进度（MVP 可不做断点续读）。

## 读完卡片

- 必含：日期、作品名、单元名、作者、阅读时长、读前心情、读后心情、一句话笔记、原文摘句。
- 读后心情：3 个选项（更松了 / 差不多 / 更沉了），不做心理评估。
- 导出：PNG；分享文案可复制。
- 本地保存：`localStorage`；不上传。

## 技术与数据

- 前端：Vite + React + TypeScript；样式用 Tailwind 或原生 CSS（实现时定）。
- 数据：`site/src/data/texts.json`、`site/src/data/moods.json`；匹配逻辑 `site/src/lib/match.ts`；文本分析 `site/src/lib/textStats.ts`。
- 无后端；无账号；无外部 API；文本只在浏览器处理。
- 部署：Qoder Sites 静态站点，公开访问；仓库格式见 [site-format.md](site-format.md)。
- 兼容：Chrome / Safari / Edge 最近两个大版本；移动端 375px 起。

## 验收标准

- [ ] 新用户从首页到读完卡片 ≤ 5 步，演示用 5 分钟文本可在 3 分钟内走完。
- [ ] 每次返回 3 个单元，均有可理解的理由；换一批可用。
- [ ] 手机 375px 与桌面 1440px 无横向滚动；正文行宽舒适。
- [ ] 读完卡片可下载 PNG；刷新后本地历史仍在。
- [ ] 无登录、无文本上传、无外部 API 依赖。
- [ ] 公网链接在无痕窗口可打开；无控制台报错。
- [ ] 18 个阅读单元均记录版权出处；敏感内容有提示；站点有“文本来源”入口。
- [ ] 键盘可操作；对比度达标；尊重 `prefers-reduced-motion`。
