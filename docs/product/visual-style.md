# 读完：视觉风格

状态：v1.1 已确认并实现（A+C 混合；v2 签到与结果布局已应用）

更新：2026-11-08

关联：[design.md](design.md)、[mvp.md](mvp.md)、[concept.md](concept.md)

## 1. 设计命题

“读完”不是资讯产品，也不是阅读管理工具，而是一张安静的阅读处方笺。用户带着一点说不清的情绪来，读一个短单元，留下一张有痕迹的卡片。

视觉要同时成立三件事：

- **安静**：没有信息流、没有催促、没有仪表盘。
- **可读完**：正文是主角，排版让 5–15 分钟的阅读不费力。
- **有痕迹**：纸张、墨色、朱红印章和一张读完卡片，让一次阅读有始有终。

关键词：**纸、墨、夜、留白、一枚朱红**。

## 2. 三个方向

| 方向 | 气质 | 适合 | 风险 |
| --- | --- | --- | --- |
| A 纸上夜读 | 暖纸、墨字、朱红；像一本安静的书 | 阅读正文、结果卡、读完卡片 | 首页记忆点较弱 |
| B 深夜书房 | 深墨底、暖白字、琥珀色；像睡前阅读 | 夜间阅读、私密感 | 白天和分享卡偏重 |
| C 意识流长卷 | 大字、错落、墨迹、滚动叙事 | 首页、读完卡片、品牌记忆 | 正文容易被打扰，实验风险高 |

**推荐：A+C 混合。** 以 A 的纸墨系统为底，正文保持安静窄栏；首页和读完卡片借用 C 的大字、错落和墨迹张力。B 作为阅读页的“夜读”主题，而不是默认皮肤。

参考站点（只借鉴排版与氛围，不复制品牌元素）：

- [Poetry Foundation](https://www.poetryfoundation.org/)：大字衬线、窄栏、极少颜色。
- [The Paris Review](https://www.theparisreview.org/)：黑白编辑感、强标题、文学刊物气质。
- [Aeon](https://aeon.co/)：大留白、安静的长文阅读。
- [单读 / 单向空间](https://www.owspace.com/)：独立出版与书封的克制感。

## 3. 色彩

| `--site-bg` | `#F5F0E6` | 页面底色，暖纸 |
| `--site-surface` | `#FBF7EF` | 卡片、纸笺 |
| `--site-fg` | `#2B2A26` | 主文字，墨色 |
| `--site-muted` | `#6F7D6A` | 次要文字，灰绿 |
| `--site-accent` | `#A44A3F` | 印章、主按钮，朱红 |
| `--site-on-accent` | `#FBF7EF` | 朱红上的文字 |
| `--site-border` | `rgba(43,42,38,0.14)` | 细线、分隔 |

### 夜读主题

| Token | 值 | 用途 |
| --- | --- | --- |
| `--site-bg` | `#15171B` | 深夜墨色 |
| `--site-surface` | `#1C1E22` | 夜间纸笺 |
| `--site-fg` | `#E9E2D3` | 暖白文字 |
| `--site-muted` | `#A9A294` | 次要文字 |
| `--site-accent` | `#C9A46A` | 夜读强调色，暖灯 |

规则：

- 朱红只给印章和关键动作，不大面积铺色。
- 不用渐变紫、玻璃拟态、彩色阴影。
- 正文与背景对比度至少 4.5:1；夜读主题不低于 7:1。

## 4. 字体与排版

- 正文/标题：`"Noto Serif SC", "Songti SC", "STSong", serif`。
- 界面/标签：`"Noto Sans SC", "PingFang SC", sans-serif`。
- 正文：17–19px，行高 1.9–2.0，字距 0.02–0.04em，行宽 34–38 个汉字。
- 阅读标题：28–40px，字重 600，行高 1.3。
- 界面文字：12–14px；标签 10–11px，字距 0.08–0.12em。
- 数字与英文：可用同族字体，不做额外装饰。
- 不把正文排成“手写体”；手写感只留给印章图形，不留给正文。

## 5. 布局

- 桌面阅读最大宽度约 720px，正文列约 620px；左侧可留一条窄元数据栏。
- 移动端 375px 起，正文单列，左右留白 20–24px。
- 首页是一张“纸”：一句问题 + 3 张心境分支卡 + “说不清”，不做营销封面；移动端首屏完整露出 4 张卡。
- 结果页：1 个主卡 + 紧凑列表；卡片像纸笺，不像仪表盘。
- 阅读页：正文连续展开，段间以小圆点分隔；诗歌默认整首；末尾一个“我读完了”。
- 读完卡片：竖版 4:5，纸面 + 大字篇名 + 摘句 + 印章 + 读前/读后心情。

## 6. 材质与细节

- 纸纹用低透明度 CSS 噪点（SVG `feTurbulence` 或 repeating-gradient），不引入大图。
- 圆角 2–4px；阴影极轻或不用；边框 1px 半透明墨色。
- 分隔线优先于卡片阴影；留白优先于装饰。
- 印章：SVG/CSS，朱红，边缘略粗糙，随机旋转 -6°–+6°；12 枚，不做手写签名。
- 插图/照片：默认不用；如果后续加入，只用公版或自制，且不抢正文。

## 7. 动效

- 180–240ms 的淡入、轻微上移、翻页式过渡。
- 选中情绪卡：轻微下沉 + 墨色边框 + 一枚小印记。
- 页面切换：像翻一页，不做弹跳、缩放、视差滚动。
- 尊重 `prefers-reduced-motion`；关闭动效后功能完整。

## 8. 组件语言

- **情绪卡**：纸笺、细边框、选中后墨色边框 + 小印章点；不用大圆角彩色块。
- **结果卡**：篇名用宋体，元信息用黑体小字；匹配标签“很合/挺合/可以看看”用细边框，不用百分比。
- **阅读正文**：窄栏、大行距、低对比装饰；进度环和计时退到边缘。
- **印章**：12 枚统一朱红；读完时选 1–3 枚。
- **读完卡片**：纸面、篇名、摘句、读后心情、印章；4:5 PNG。
- **文本来源**：全屏抽屉，像书末的版权页；不打断阅读。

## 9. 不要做

- 渐变紫、玻璃拟态、厚重阴影、彩色图标墙。
- 卡片瀑布流、无限滚动、打卡日历、连续天数。
- 大圆角 + 高饱和 + 动画弹跳的“App 模板感”。
- 把手写体用在正文或按钮上。
- 用 AI 生成图片替代真实的文字氛围。

## 10. 已确认

- 最终方向：A+C 混合。
- 默认主题：日纸；夜读作为阅读页可选主题。
- 首页第一屏：安静提问式；保留“读完”大字与朱红小印作为记忆点，不单独做封面页。
- 字体：宋体正文 + 黑体界面。
