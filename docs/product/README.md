## 一句话

说出此刻的心情和可用时间，读完从公共版权文本库里为你配 3 篇读得完的短篇/节选；你选一篇，它陪你按节奏读完，并留下一张读完卡片。

## 当前决策

- 赛道：LifeHack 生活娱乐。
- 核心循环：心情签到 → 配文 → 选文 → 阅读 → 读完卡片。
- 阅读对象：2–15 分钟、能独立读完的“阅读单元”，不是整本书。
- 文本来源：中国 + 美国双公版中文文本（现代文学、古典诗词、古典散文/小说节选）。
- 匹配方式：情绪标签 + 关键词 + 时间/体裁/难度，可解释，不做 AI 摘要。
- 仓库格式：站点源码在 `site/`，作为 Qoder Sites 项目根；`.qoder.site` 由工具生成。
- MVP 不做：账号、社交 feed、AI 摘要/问答、后端、整本书阅读。
