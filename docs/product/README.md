状态：设计已定稿，本地实现完成，待公网部署

- 工作名：读完
- 更新：2026-11-07

## 一句话

说出此刻的心情和可用时间，读完按匹配度为你排出 10+ 个读得完的公共版权短篇/节选；你选一个，它陪你按节奏读完，并留下一张读完卡片。

## 当前决策

- 赛道：LifeHack 生活娱乐。
- 核心循环：心情签到 → 配文 → 选文 → 阅读 → 读完卡片。
- 阅读对象：2–15 分钟、能独立读完的“阅读单元”，不是整本书。
- 结果列表：按综合匹配度降序，至少 10 个；前 3 个大卡片、其余紧凑列表；卡片用“很合 / 挺合 / 可以看看”。
- 自由输入：按中等权重 0.15 参与排序，不压过状态卡和需求卡。
- 文本来源：以中国公版为底线，优先中国 + 美国双公版；首批 18 个单元全部双公版。
- 内容规模：18 个只用于概念验证；首次公开版目标 48–60 个，后续 100+，见 [content-plan.md](content-plan.md)。
- 匹配方式：情绪标签 + 关键词 + 时间/体裁/难度，可解释，不做 AI 摘要。
- 首页：直接进入心情签到，不做单独封面。
- 完成感：读完卡片 + 12 枚朱红预设计印章（读完时选 1–3 枚，不做网页手写签名）+ 读后心情 + 竖版 4:5 分享卡。
- 阅读节奏：散文/小说的段落笔记可选，不阻断继续阅读；MVP 不做断点续读。
- 原文摘句：每篇预置一句，用户可在读完前替换。
- 仓库格式：站点源码在 `site/`，作为 Qoder Sites 项目根；`.qoder.site` 由工具生成。
- MVP 不做：账号、社交 feed、AI 摘要/问答、后端、整本书阅读、网页手写签名。
