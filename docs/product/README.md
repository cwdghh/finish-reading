## 一句话

说出此刻的心情和可用时间，读完按匹配度为你排出 8–10 个读得完的公共版权短篇/节选；你选一个，它陪你按节奏读完，并留下一张读完卡片。

## 当前决策

- 赛道：LifeHack 生活娱乐。
- 核心循环：心情签到 → 配文 → 选文 → 阅读 → 读完卡片。
- 阅读对象：2–15 分钟、能独立读完的“阅读单元”，不是整本书。
- 签到：四步顺序问诊（此刻 → 更具体 → 想要 → 时间），280ms 自动推进；桌面实时处方签，移动端固定主操作。
- 自由输入：独立入口，可无心境直接开始；本地关键词建议可修改；无心境时中性权重。
- 结果列表：默认 9 个（8–10 范围内），1 个主卡 + 紧凑列表；主标题为作品名，`全文/节选/整首` 为标签；“调整条件”与“换一批”分开。
- 匹配标签：很合 ≥ 0.82、挺合 ≥ 0.70、可以看看 < 0.70；弱匹配时标题“今天先读一篇”。
- 新鲜度：日期种子、当天缓存、7 天最近展示排除、最近读过排除、会话 nonce；同日稳定，次日/换一批变化。
- 文本来源：以中国公版为底线；当前 60 个单元全部为中国 + 美国双公版。
- 内容规模：60 个（诗/词 27、现代散文 12、小说 7、古文 14），已满足 48–60 目标，见 [content-plan.md](content-plan.md)。
- 匹配方式：心境/需求标签 + 本地关键词 + 时间/体裁/难度，可解释，不做 AI 摘要。
- 完成感：读完卡片 + 12 枚朱红预设计印章（读完时选 1–3 枚）+ 读后心情（无默认值）+ 竖版 4:5 PNG。
- 阅读节奏：默认连续滚动，诗歌默认整首、可切逐句；默认聚焦当前段/句，可关闭；末尾一个“我读完了”，笔记可选；不做断点续读。
- 原文摘句：每篇预置一句，用户可在读完前替换。
- 仓库格式：站点源码在 `site/`，作为 Qoder Sites 项目根；`.qoder.site` 由工具生成。
- MVP 不做：账号、社交 feed、积分/连续天数/排行榜、AI 摘要/问答、后端、整本书阅读、网页手写签名。
