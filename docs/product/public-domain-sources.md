# 公版书来源与核验流程

状态：已调研，待逐篇核验  
更新：2026-11-07

目标：为“读完”找到**可公开使用、可校对、适合切成短阅读单元**的中文文本来源。不是找“能下载整本书”的网站，而是找“能合法引用原文、并能核对版本”的来源。

## 版权底线

- 中国：作者逝世超过 50 年（一般规则），作品进入公有领域。2026 年以作者 1975 年及以前逝世为安全线；1976 年逝世的作者到 2027 年才进入公有领域。
- 美国：Project Gutenberg、HathiTrust、Internet Archive 等按美国法律判断。2026 年 1930 年及以前发表的作品已进入美国公有领域；本项目优先 1929 年前发表，但不强制。
- 目标：**中国公版为底线**；优先中国 + 美国双公版。仅中国公版的文本可以收录，但必须在元数据和“文本来源”页标注 `public-domain-cn`，说明适用法域。
- 无法确认中国公版状态的，不进入公开文本库。
- 只使用原文；不复制现代出版社的校注、标点本、白话翻译、导读和赏析——这些可能仍有版权。
- 每个单元记录：作者、逝世年份、首次发表年份、来源、许可、核对日期。站点提供“文本来源”页/弹窗。

## 推荐组合

1. **诗词**：先用 `chinese-poetry` 的 JSON 找文本，再用中文维基文库或扫描件核对。
2. **古典散文/小说**：中文维基文库或 Project Gutenberg；用国家图书馆/Internet Archive 的影像核对。
3. **近现代公版**：中文维基文库中带公版模板的页面；优先 1929 年前发表的作品。
4. **注释**：自己写 2–3 条短注；不复制现代出版社的注释。
5. **版本**：至少两个来源交叉核对；有影像时以影像为准。

## 核验流程

1. 先定“阅读单元”（见 [content-plan.md](content-plan.md)），不要先找整本书。
2. 找到单元所在的作品与版本。
3. 核对作者逝世年份、首次发表年份、来源页许可。
4. 从两个来源对照文本；记录差异，选更可靠的一个。
5. 写入元数据：`sourceName`、`sourceUrl`、`license`、`accessedAt`、`publicationYear`、`authorDeathYear`、`copyrightScope`。
6. 在站点“文本来源”页列出每个单元的来源与许可。
7. 如无法确认版权或文本质量，换一篇，不冒险。

## 已验证的例子

- 鲁迅《秋夜》：中文维基文库页面标注作者鲁迅、出自《野草》、1924 年，版权模板 `{{Pd/1996|1936}}`；文本转自《鲁迅全集》1948 年版扫描页。可作为“现代公版 + 维基文库”的样板。
- Project Gutenberg 中文藏书包含《诗经》《礼记》《易经》《山海经》《三字经》《百家姓》等古典文本，可作为古典单元的来源或校对。
- `chinese-poetry` 仓库为 MIT 许可，包含唐诗、宋诗、宋词、诗经、楚辞、论语等 JSON，适合诗词初筛。
- ctext.org 的 FAQ 明确反对抓取/转载，因此只用于检索和核对，不作为站点文本来源。

## 不推荐

- 直接复制现代出版社的校注本、白话译本、赏析（版权风险）。
- 从百度百科、知乎、豆瓣、微信公众号等复制文本（来源不明、版本不可靠）。
- 从 ctext.org 批量抓取（违反其使用条款）。
- 使用微信读书、豆瓣阅读等平台的版权文本。
- 只凭“作者去世很久”判断，不核对具体作品的发表年份和来源许可。
