# 读完：初步设计计划

状态：设计稿 v0.1（核心交互已确认）  
更新：2026-11-07  
关联：[concept.md](concept.md)、[mvp.md](mvp.md)、[content-plan.md](content-plan.md)、[site-format.md](site-format.md)

## 1. 设计命题

一张安静的阅读处方笺。不是信息流，不是阅读管理工具；用户说出此刻的状态，得到一份按匹配度排好的短阅读清单，读完一个单元，盖一枚印章。

三个关键词：**安静、可读完、有痕迹**。

## 2. 视觉方向

- **纸张与墨**：暖纸底、墨色字、低饱和；朱红只用于印章和关键动作。
- **字体**：正文用 Noto Serif SC，界面用 Noto Sans SC；正文行高 1.9–2.0，行宽 34–38 个汉字。
- **材质**：细边框、轻微纸纹、少阴影；卡片像纸笺，不像仪表盘。
- **动效**：180–240ms 的淡入/滑动；检查点之间像翻一页；尊重 `prefers-reduced-motion`。
- **反模式**：不做渐变紫、玻璃拟态、卡片瀑布流、无限滚动、打卡日历。

设计变量映射到 Qoder Sites 的 `--site-*`：

| 变量 | 用途 | 建议默认 |
| --- | --- | --- |
| `--site-bg` | 页面底色 | 暖纸 `#F5F0E6` |
| `--site-fg` | 主文字 | 墨色 `#2B2A26` |
| `--site-accent` | 印章/主按钮 | 朱红 `#A44A3F` |
| `--site-on-accent` | 主按钮文字 | 纸色 `#FBF7EF` |

| `--site-space` | 间距倍率 | 1 |

## 3. 页面与流程

### 3.1 首页 = 心情签到

不做营销封面。打开就是问题：

> 此刻，你更接近哪一种？

6 张状态卡：

- 累但不想睡 — “身体关机了，脑子还在转”
- 心里有点堵 — “说不出具体为什么”
- 想逃开一会儿 — “不想面对现实”
- 需要一点力气 — “想被推一把”
- 今天还不错 — “想延长一点好心情”
- 说不清 — “那就随便看看”

流程图（文字）：

```text
[读完]
此刻，你更接近哪一种？
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 累但不想睡 │ │ 心里有点堵 │ │ 想逃开一会儿 │
└──────────┘ └──────────┘ └──────────┘
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 需要一点力气│ │ 今天还不错 │ │ 说不清     │
└──────────┘ └──────────┘ └──────────┘
[用一句话说说]（可选，60 字）
[下一步]
```

第 2 步：想要的感觉（被安慰 / 被逗笑 / 被点醒 / 被陪着 / 想看美的东西 / 都行）。  
第 3 步：时间（5 / 15 / 25 分钟）+ 体裁（诗 / 散文 / 小说 / 古文 / 随便）。这两项是偏好，不是硬筛选。  
三步完成，进度点显示 1/3、2/3、3/3；可返回；自由输入可跳过。

交互：卡片选中时出现墨色边框和一枚小印记；自由输入会被原样引用到结果页，例如“你说：今天有点累”。

### 3.2 配文结果

```text
为你排了 18 个 · 按匹配度
你说：今天有点累
[重新匹配]

最匹配
┌────────────────────────────────┐
│ 《背影》· 车站买橘        很合 │
│ 朱自清 · 散文 · 8 min · 薄雾   │
│ 你选了“想被安慰”，这篇句子慢… │
│ 试读：……                       │
│ [读这个]                       │
└────────────────────────────────┘

更多可读
04 《秋夜》· 全文     鲁迅 · 8 min  挺合
05 《月下独酌》       李白 · 3 min  挺合
...
[展开全部 18 个]
```

- 10+ 个单元，按综合匹配度降序；前 3 个用大卡片，标“最匹配”；其余用紧凑列表。
- 每张卡展示：作品名 · 单元名、作者、体裁、时长、天气、匹配标签、推荐理由、1–2 句试读；超出可用时间的标“稍长”；有敏感内容的显示提示。
- 匹配标签建议用“很合 / 挺合 / 可以看看”，不直接展示 92 分；分数只放在“匹配详情”里，避免像推荐算法。
- 不提供无限“换一批”；提供“重新匹配”（回到签到）和可选的“随机一篇”。

### 3.3 阅读界面

```text
[←] 《背影》· 车站买橘        2/4   ⏱ 06:12
──────────────────────────────────
正文……
正文……
[用一句话记住这一段]（可选）
[读完这段]
```

- **诗/词**：整首单列展示；可切换“逐句显现”；显示一句读前上下文。
- **散文/小说**：3–5 个检查点，每段 300–800 字；一次只显示一段；段末可写一句“这段在讲什么”。
- **古文**：原文 + 2–3 条短注；注释可开关；不做全文翻译。
- **通用**：进度环、已用时间（不是倒计时警报）、字号/行距/纸色/夜间模式；退出时提示进度保存。
- 不无限滚动；不自动跳段；检查点之间有一次“翻页”式的过渡。
- 阅读界面不出现印章选择，保持安静；印章留到读完。

### 3.4 读完卡片

```text
┌──────────────────────────────┐
│ 读完 · 2026.11.07            │
│ 《背影》· 车站买橘            │
│ 8 分钟 · 薄雾                 │
│ “你写下的：……”              │
│ 读前 心里有点堵 → 读后 更松了 │
│ [印章] [印章]                 │
└──────────────────────────────┘
[保存卡片]  [再读一个]  [回到首页]
```

- 读完时选 1–3 枚预设计印章；印章轻微旋转，像真的盖上去。
- 读后心情 3 个选项：更松了 / 差不多 / 更沉了；不做心理评估。
- 分享卡建议竖版 4:5，适合小红书/朋友圈；可下载 PNG。
- 本地保存到“处方笺”历史，可重新打开。

### 3.5 文本来源

页脚入口，打开一个安静的全屏抽屉或独立页：列出每个单元的作品、作者、发表年、来源、许可、核对日期；仅中国公版的文本明确标注。

## 4. 关键交互

- **心情卡**：单击选中，不弹窗；选中后轻微下沉 + 墨色边框。
- **自由输入**：可选，不强制；结果页引用原话，让用户感到被听见。
- **匹配标签**：用人话（很合/挺合/可以看看）代替百分制；详情里可看标签和分数。
- **阅读计时**：显示已用时间，不制造倒计时压力；计划时间只作为参考。
- **印章**：只预设、不手写；选择 1–3 枚，随机轻微旋转；不做“连续打卡”压力。
- **退出**：提示“进度已保存在本地”或“这次不会保存”，不假装有账号同步。
- **内容提示**：涉及死亡/离别/疾病/暴力/沉重意象的单元，在结果卡和阅读前提示；用户可选择避开。

## 5. 匹配与排序

- 输入：状态卡、需求卡、时间、体裁、自由输入。
- 时间/体裁是偏好权重，不是硬筛选；结果始终尽量给出 10+ 个。
- 建议权重：需求 0.25、情绪 0.20、自由输入 0.15、时间 0.15、体裁 0.10、效价/唤醒度 0.10、难度 0.05；再加多样性加分（不同体裁/作者）。
- 自由输入：关键词词典 + 与 `moodDescription` 的字二元组余弦相似度；不做 AI，不声称“懂你”。
- 推荐理由：引用用户选中的词 + 文本特征 + 时间，例如“你选了‘想被安慰’，又只有 10 分钟；这篇 8 分钟，句子慢，结尾暖。”
- 结果：全部排序，默认展示前 10 个，可展开；前 3 个突出；最近读过的靠后或排除。
- 不做“无限刷新”，避免变成推荐流。

## 6. 印章系统

12 枚，分三组：

- 情绪：被安慰 / 被点醒 / 想笑 / 想哭 / 平静 / 有力量
- 状态：夜读 / 慢读 / 读完 / 想再读
- 内容：好句子 / 想记住 / 想分享

视觉：SVG/CSS，朱红/墨蓝/墨绿，边缘略粗糙；字号小，像藏书印；随机旋转 -6°–+6°；不做手写签名。读完时选 1–3 枚，盖在卡片右下角或文字旁边。

## 7. 文案语气

- 温和、具体、克制；不说“治愈”“疗愈”“心理测评”。
- 示例：  
  - “你选了‘想被安慰’，这篇的节奏慢，像有人陪你坐一会儿。”  
  - “只有 5 分钟也没关系，读一首诗就够了。”  
  - “读不完也可以停，下一次再从这一页开始。”
- 避免：夸张承诺、打卡压力、排行榜、连续天数。

## 8. 技术映射

- Vite + React + TypeScript；单入口；MVP 用视图状态机，不引入路由；`prepare_site` 可先用 `spa: false`。
- 数据：`site/src/data/texts.json`、`moods.json`、`stamps.json`；匹配 `site/src/lib/match.ts`；文本统计 `site/src/lib/textStats.ts`。
- 本地：`localStorage` 保存偏好、历史、最近读过；不登录、不上传。
- Qoder Sites：`site/` 为项目根；`.qoder.site` 由设计工作台生成；样式消费 `--site-*`；发布用 `prepare_site` / `publish_site`。
- 组件：`MoodCard`、`StepDots`、`ResultCard`、`RankList`、`ReadingPane`、`Checkpoint`、`StampTray`、`FinishCard`、`SourceDrawer`。
- 响应式：375px 起；阅读正文单列；桌面最大宽度约 720px；键盘可操作；对比度达标。

## 9. 已确认的设计选择

1. 首页直接进入心情签到，不做单独封面。
2. 结果卡用“很合 / 挺合 / 可以看看”；分数只放在“匹配详情”里。
3. 印章只在读完时选 1–3 枚；阅读界面保持安静。
4. 读完卡片用竖版 4:5。
5. 结果默认展示前 10 个，可展开全部 18 个。
6. MVP 用单页状态机；如果后续需要分享具体结果，再加 query 参数或路由。
