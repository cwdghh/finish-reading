# 读完：设计 v2.0

状态：v2 本地实现与验收通过；公网部署暂停

更新：2026-11-08

关联：[concept.md](concept.md)、[mvp.md](mvp.md)、[content-plan.md](content-plan.md)、[site-format.md](site-format.md)

## 1. 设计命题

一张安静的阅读处方笺。不是信息流，不是阅读管理工具；用户说出此刻的状态，得到一份按匹配度排好的短阅读清单，读完一个单元，盖一枚印章。

三个关键词：**安静、可读完、有痕迹**。

v2 保留 v1 的纸张/墨字/朱红方向，把签到从“9 张卡平铺”改为“四步顺序问诊”：每一步只问一件事，选完自动翻到下一步；桌面左侧像医生写处方签一样逐行留下“此刻 / 想要 / 时间”。

## 2. 视觉方向

- **纸张与墨**：暖纸底、墨色字、低饱和；朱红只用于印章和关键动作。
- **字体**：正文 Noto Serif SC，界面 Noto Sans SC；正文行高 1.9–2.0，行宽 34–38 个汉字。
- **材质**：细边框、轻微纸纹、少阴影；卡片像纸笺，不像仪表盘。
- **动效**：180–280ms 淡入/滑动；步骤切换像翻一页；尊重 `prefers-reduced-motion`。
- **反模式**：不做渐变紫、玻璃拟态、卡片瀑布流、无限滚动、打卡日历、积分/连续天数/排行榜。

## 3. 页面与流程

### 3.1 首页 = 四步签到

不做营销封面。打开就是问题：

> 此刻，你更接近哪一种？

桌面：左侧缩小“读完”字标 + 实时处方签 + 一句说明；右侧步骤轨道与问题。移动端：压缩品牌区，首屏完整露出 3 张心境卡 + “说不清”，底部固定主操作栏。

```text
[读完]                                      [处方笺] [文本来源]
┌──────────────┐  01 此刻  02 更具体  03 想要  04 时间
│ 读            │  ─────────────────────────────────
│ 完   〔读〕    │  01 / 此刻
│               │  此刻，你更接近哪一种？
│ 处方签  正在写 │  ┌────────┐ ┌────────┐ ┌────────┐
│ 此刻  低落…   │  │ 低落    │ │ 疲惫    │ │ 还不错  │
│ 想要  —       │  └────────┘ └────────┘ └────────┘
│ 时间  15 分钟 │  ┌────────────────────┐
│               │  │ 说不清 / 跳过       │
│ “一句话…”     │  └────────────────────┘
└──────────────┘  或者直接说一句 [___________]
                  [说不清，先跳过 →]
```

四步：

1. **此刻**：低落 / 疲惫 / 还不错 3 张分支卡 + “说不清”。分支卡展示该方向的叶节点，例如“心里有点堵 / 想逃开一会儿 / 有点委屈”。
2. **更具体**：根据分支动态显示 2–3 个叶节点；可跳过。若在自由输入里点选了建议叶节点，主按钮直接跳到第 3 步。
3. **想要**：按分支重排 4 个主需求，另 2 个收进“更多选择”。
   - 低落：被安慰 / 被陪着 / 被点醒 / 都行 +〔被逗笑 / 想看美的东西〕
   - 疲惫：被安慰 / 被逗笑 / 被点醒 / 都行 +〔被陪着 / 想看美的东西〕
   - 还不错：被逗笑 / 想看美的东西 / 被点醒 / 都行 +〔被安慰 / 被陪着〕
4. **时间**：5 / 15 / 25 分钟 + 诗 / 散文 / 小说 / 古文 / 随便；可选内容偏好折叠；唯一主按钮“生成处方”。

交互细节：

- 选择分支/叶节点/需求后 **280ms** 自动推进；期间显示选中印记。
- 保留“上一步”；“说不清”路径返回第 1 步。
- 步骤切换后焦点移到新问题 H1，`aria-live` 播报“第 N 步，……”。
- 自由输入最多 80 字，给出可点选修改的心情建议与“你提到”的主题；不选心境也能继续。
- 无积分、无连续天数、无排行榜。

### 3.2 自由输入独立入口

- 入口在 Q1 内，文案“或者直接说一句 / 一句话也能开始”。
- 输入后本地词典推断主题与建议叶节点，例如“今天有点累，脑子停不下来”→ 建议“累但不想睡 / 脑子停不下来”，主题“疲惫 / 夜 / 脑子停不下来”。
- 建议标签可点选、可取消；点选后仍可继续选需求和时间。
- 主按钮“就按这句话配”可直接生成结果，不要求选心境。
- 未选心境时使用中性权重；结果页写“未选状态 · 按你写的话来配”，并列出主题与“这轮 5 篇因此排得更前”。
- 不调用 AI，不上传文本。

### 3.3 配文结果

```text
配文结果 / 从 53 个单元里
这轮先看 9 个
前几张是稳定的锚点……
[有点委屈] [被安慰] [15 分钟] [散文]
[换一批 →] [调整条件]

最稳的一篇
┌────────────────────────────────┐
│ 01                    [很合] [节选] │
│ 《背影》                         │
│ 车站买橘                         │
│ 朱自清 · 散文 · 8 分钟 · 薄雾    │
│ “他给我拣定了靠车门的一张椅子…” │
│ 读起来会是薄雾的感觉。……        │
│ + 匹配详情                       │
│ [读这个 →]        读完大约 8 分钟 │
└────────────────────────────────┘

同一批里还可以读             02 — 09
02 《风筝》 鲁迅 · 散文 · 7 分钟 · 晴 · 全文 [很合]
   它的怀旧，离你此刻的状态不远。……
...
```

- 默认 9 个（8–10 个范围内）；1 个主卡 + 8 个紧凑行。
- 主标题为作品名，单元名作副标题；`全文 / 节选 / 整首` 是标签，不再当标题。
- 主卡展示匹配标签、体裁标签、内容提示、“因你写的话”标签、摘句、1–2 句理由；匹配详情折叠。
- 紧凑行展示作品名、单元名、作者/体裁/时长/天气/类型、标签、一句理由。
- 标签按分数阈值：很合 ≥ 0.82、挺合 ≥ 0.70、可以看看 < 0.70；与弱匹配线一致。
- 顶级分 < 0.70 时标题变“今天先读一篇”，提示匹配不强、可以先读短的。
- “调整条件”回到第 04 步；“换一批”排除当前 9 个并生成下一批，两者语义分开。
- 结果页展示“避开的内容”“最近读过的”“最近展示过的”等筛选说明。

### 3.4 阅读界面

```text
[←] 《背影》· 车站买橘         62%   ⏱ 06:12
──────────────────────────────────
正文……
正文……
·（段间分隔）
正文……
[用一句话记住这次阅读]（可选）
[我读完了]
```

- **默认连续阅读**：散文/小说/古文的所有段落一次展开，向下滚动即可读完；不再要求逐段点击“下一页”。
- **诗/词**：默认整首展开；可切换“逐句”做慢读，逐句模式才出现“下一句”。
- **散文/小说**：段与段之间用一枚小圆点分隔；整篇只有末尾一个“我读完了”。
- **古文**：原文 + 2–3 条短注；注释可开关；不做全文翻译。
- **通用**：进度环按滚动位置显示百分比；已用时间（不是倒计时）；字号/行距/纸色/夜间模式；减少重复操作。
- 阅读界面不出现印章选择，保持安静。
- 阅读页顶部提示“正文已展开 / 整首已展开，按自己的速度向下读”。

### 3.5 读完卡片

```text
┌──────────────────────────────┐
│ 读完 · 2026.11.08            │
│ 《背影》                      │
│ 车站买橘                     │
│ 朱自清 · 散文 · 节选 · 8 分钟 │
│ 摘句：“……”                  │
│ 读前 有点委屈 → 读后 更松了   │
│ [印章] [印章]                 │
└──────────────────────────────┘
[收下这张卡片] [下载 4:5 PNG]
[再读一个] · [处方笺 · 读过的卡片] · [回到首页] · [文本来源]
```

- 节选单元在标题下显示“读到这里只是节选。去中文维基文库读《作品》全文 ↗”；全文单元显示“这篇已经是全文。打开《作品》原文 ↗”。外链新标签页打开，带 `noopener noreferrer`。
- 读后心情 3 个选项：更松了 / 差不多 / 更沉了；**初始不选中**，必须显式选择。
- 选 1–3 枚预设计印章；印章轻微旋转，像真的盖上去。
- 原文摘句每篇预置一句，可从正文替换。
- 竖版 4:5 PNG（1080×1350），下载会同时存入处方笺。
- 移动端固定底部栏：“收下卡片 / 下载 PNG”，并显示“先选一个读完的感觉 / 再选 1 枚印章 / 下载会同时存入处方笺”。
- 本地保存到“处方笺”历史，可重新打开；主标题为作品名。

### 3.6 处方笺与文本来源

- 历史导航按钮显示“处方笺”，`aria-label` 为“处方笺，查看读过的卡片”，有记录时追加“共 N 张”。
- 历史卡以作品名为主标题，单元名为副标题；显示读前/读后心情、摘句、印章与日期。
- 文本来源用安静的全屏抽屉：作品、作者、发表年、来源、许可、核对日期；全部为双公版。

## 4. 关键交互与无障碍

- **自动推进**：选择后 280ms 进入下一步；点击“上一步”或返回会取消待执行计时。
- **焦点**：步骤切换后聚焦新 H1；主内容有跳转链接；所有卡片/芯片是语义按钮，使用 `aria-pressed`。
- **播报**：`role="status" aria-live="polite"` 播报当前步骤；底部摘要也随选择更新。
- **固定栏**：移动端签到栏与完成栏固定在视口底部；其祖先不能有 transform 动画，否则 `position: fixed` 会失效。
- **减少动效**：`prefers-reduced-motion` 下动画缩短到近 0，滚动改为自动。
- **阅读计时**：显示已用时间，不制造倒计时压力。
- **内容提示**：涉及死亡/离别/疾病/暴力/沉重意象的单元，在结果卡和阅读前提示；用户可选择避开。
- **退出**：明确提示“这次不会保存进度”，不假装有账号同步。

## 5. 匹配、抽样与新鲜度

- 输入：心境分支/叶节点、需求、时间、体裁、自由输入、内容偏好。
- 有心境权重：需求 0.25、心境 0.20、自由输入 0.15、时间 0.15、体裁 0.10、效价/唤醒 0.10、难度 0.05。
- 无心境权重：需求 0.18、心境 0.05、自由输入 0.36、时间 0.15、体裁 0.10、效价/唤醒 0.05、难度 0.11。
- 自由输入：本地词典 + 与 `moodDescription` 的字二元组相似度；最多 5 篇标“因你写的话”；不声称“懂你”。
- 推荐理由：一个主要维度（需求/心境/自由输入/时间/体裁/天气）+ 该单元独有的 `whyItFits`；模板轮换，避免所有卡片同一开头。
- 排序：先取 3 个稳定锚点（作者/体裁重复降权），其余按 0.04 分数带分组，在带内用种子 PRNG 抽样；不会把最相关的文章随机掉。
- 日期种子：`hash(date + branch + leaf + need + time + form + free input)`；同日同答案稳定，次日变化。
- 当天缓存 `duwan:batch:v1`；最近展示 `duwan:shown:v1` 保留 7 天；最近读过继续排除。
- “换一批”：session nonce + batchIndex 生成新种子，并排除当前批次；这是有边界的换一批，不是无限刷新。

## 6. 印章系统

12 枚，统一朱红，分三组：

- 情绪（6）：被安慰 / 被点醒 / 想笑 / 想哭 / 平静 / 有力量
- 状态（4）：夜读 / 慢读 / 读完 / 想再读
- 内容（2）：好句子 / 想记住

视觉：SVG/CSS，朱红印章，边缘略粗糙；字号小，像藏书印；随机旋转 -6°–+6°；不做手写签名。读完时选 1–3 枚，盖在卡片上。

## 7. 文案语气

- 温和、具体、克制；不说“治愈”“疗愈”“心理测评”。
- 示例：
  - “你选了‘被安慰’，这篇的节奏慢，像有人陪你坐一会儿。”
  - “只有 5 分钟也没关系，读一首诗就够了。”
  - “读不完也可以停，下一次再从这一页开始。”
- 避免：夸张承诺、打卡压力、排行榜、连续天数、积分。

## 8. 技术映射

- Vite 8 + React 19 + TypeScript；单入口；视图状态机，不引入路由；`spa: false`。
- 数据：`site/src/data/texts.json`、`moods.ts`；匹配 `site/src/lib/match.ts`；自由输入 `freeInput.ts`；文本统计 `textStats.ts`；本地记录 `storage.ts`。
- 文本校验：`site/scripts/validate-texts.mjs`，接入 `npm run build`。
- 本地：`localStorage` 保存偏好、历史、最近展示、当天批次；`sessionStorage` 保存会话 nonce；不登录、不上传。
- Qoder Sites：`site/` 为项目根；`.qoder.site` 由设计工作台生成；样式消费 `--site-*`。
- 响应式：375px 起；阅读正文单列；桌面最大宽度约 720px；键盘可操作；对比度达标。
- v2 本地验收：375×812 / 1440×1000 完整走通，控制台 0 错误，无横向溢出。

## 9. 已确认的设计选择

1. 产品名保留“读完”。
2. 首页直接进入四步签到，不做单独封面。
3. Q1 只用低落/疲惫/还不错 3 个分支 + 说不清；Q2 动态叶节点；Q3 按分支重排需求。
4. 选择后 280ms 自动推进；保留上一步；焦点与播报跟随步骤。
5. 自由输入是独立入口，可无心境直接开始；中性基线 + 可修改建议。
6. 结果默认 9 个；1 主卡 + 紧凑列表；“调整条件”和“换一批”分开。
7. 标签按分数阈值，不按名次固定“很合”。
8. 结果卡/完成卡以作品名为主标题，`全文/节选/整首` 为标签。
9. 同日同答案稳定；次日与“换一批”变化；最近展示 7 天内优先排除。
10. 读后心情无默认值；移动端固定保存/下载；下载会同时存入处方笺。
11. 印章只在读完时选 1–3 枚；12 枚统一朱红。
12. 保留 A+C 纸张/墨字视觉；正文窄栏；减少动效可用。
13. v1 公网站点保留，但 v2 部署等待用户确认。
