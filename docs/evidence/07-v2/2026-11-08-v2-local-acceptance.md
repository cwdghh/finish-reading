## 9. 标签阈值与理由

- 很合 ≥ 0.82；挺合 ≥ 0.70；可以看看 < 0.70。弱匹配线同为 0.70。
- 强路径实测：0.904、0.863 → 很合；其余 7 个 0.757–0.808 → 挺合。
- 弱路径实测：顶级分 0.676 → 可以看看；9 个全部可以看看，与“今天先读一篇”一致。
- 理由示例（同一批结果中不重复开头）：
  - “读起来会是薄雾的感觉。细节密、句子慢，像有人坐在旁边，不急着安慰你，只陪你想起一个人。”

## 11. 无障碍与响应式

- 步骤切换：焦点移到新问题 H1；`role="status" aria-live="polite"` 播报当前步骤。
- 选择控件：分支/叶节点/需求/时间/体裁/印章均为按钮，使用 `aria-pressed`。
- 处方笺入口：`aria-label="处方笺，查看读过的卡片"`；有记录时追加“共 N 张”。
- `prefers-reduced-motion`：动画时长 `1e-05s`，滚动 `auto`。
- 横向溢出：375 与 1440 均为 `scrollWidth === clientWidth`。
- 控制台：375/1440 全流程、自由输入、弱匹配均为 0 error、0 pageerror。
- 移动端自由输入滚动到底：提示区底部 704px，固定栏顶部 749px，内容不被永久遮挡。
