# 边界条件回归与阅读间距修正

日期：2026-11-08  
环境：本地 `vite preview`（`http://127.0.0.1:4173/`），Chrome headless，60 个单元构建  
范围：自由输入、说不清、内容偏好、连续换批、读完保存、诗歌逐句、320px 窄屏、localStorage 不可用、段落间距

## 1. 阅读段落间距

问题来自 v2 连续阅读沿用分页时的 section 间距：`.reading-section + .reading-section` 额外加了 34px，并插入一个圆点分隔（下方再留 22px），所以在《记承天寺夜游》这类“每页一段”的文本里出现了明显大空格。

修正：删除 section 之间的额外 margin 和圆点分隔，统一使用段落自身的 `1.25em` 间距。实测相邻段间隔约 21px。

## 2. 边界回归结果

| 场景 | 结果 | 备注 |
| --- | --- | --- |
| 自由输入只有空格 | 通过 | 主按钮为“说不清，先跳过”，进入 Q3 |
| 自由输入只有标点“。。。” | 通过 | 主按钮为“就按这句话配”；9 个结果，弱匹配标题“今天先读一篇” |
| 自由输入 100 字 | 通过 | 输入框上限 80 字 |
| 自由输入建议 | 通过 | “今天有点累，脑子停不下来”→ 建议“累但不想睡 / 脑子停不下来”，主题“疲惫 / 夜 / 脑子停不下来” |
| 说不清路径 | 通过 | 不选心境、5 分钟、小说；9 个结果 |
| 避开全部内容提示 | 通过 | 避开 13 个单元，仍有 9 个结果，并显示避开提示 |
| 连续换批 5 次 | 通过 | 6 批各 9 个；第 1–5 批不重复；第 6 批出现重复提示“可选单元不多了，这一轮可能会和前几批重复” |
| 读完保存守卫 | 通过 | 未选心情/印章时按钮禁用；只选心情仍禁用；心情 + 1 枚印章启用；3 枚后第 4 枚禁用；取消后可再选 |
| 诗歌逐句 | 通过 | 7 次“下一句”后出现“读完了”，进入读完页 |
| 320×568 窄屏 | 通过 | 首页、Q4、结果、阅读、读完页均无横向溢出 |
| localStorage 不可用 | 通过 | 首页正常，仍生成 9 个结果；无崩溃 |

所有场景控制台错误 0、页面异常 0、失败请求 0。完整数据见 [2026-11-08-edge-cases.json](2026-11-08-edge-cases.json)。

连续换批出现重复是 60 个单元的容量边界：6 批 × 9 个已超过一半文本，重复不可避免；本轮补了明确提示，而不是静默重复。
