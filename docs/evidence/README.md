# Qoder 过程证据

论坛作品帖要求说明“用 Qoder 做出来的过程”，并建议多放截图。这个目录保存开发与部署证据。

## 目录建议

- `01-setup/`：项目初始化、技术栈、第一版页面。
- `02-mood-input/`：心情签到交互的生成与修改。
- `03-matching/`：匹配逻辑、结果卡迭代。
- `04-reading/`：阅读模式、检查点、排版调整。
- `05-finish-card/`：读完卡片与导出。
- `06-deploy/`：Qoder Sites 发布设置、公网访问。
- `07-v2/`：v2 四步签到、自由输入、结果新鲜度、连续阅读、段落聚焦、60 个文本、375/1440 本地与公网验收。
- `08-forum/`：论坛帖过程截图、发布记录与链接。

## 命名

`YYYY-MM-DD-HHMM-简短说明.png`，例如 `2026-11-12-2130-mood-cards-v2.png`。

## 记录什么

- 关键提示词/任务描述（截图或文本）。
- Qoder 生成结果与你手动修改的对比。
- 遇到的问题、报错、修复过程。
- 移动端/桌面端预览。
- Qoder Sites 发布设置与公网 URL。
- 最终核心界面截图。

## 隐私

- 不放入账号密码、API Key、个人证件、未公开个人信息。
- 截图中的个人信息打码。
- 只保留可公开使用的内容。
