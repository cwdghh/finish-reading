# 报名、开发与提交清单

截止时间：**2026-11-30 18:00**（报名与作品提交相同）。规则详见 [competition.md](competition.md)。

## 一、资格与报名

- [ ] 确认本人符合参赛对象要求（全国在校大学生，含港澳台，不限专业）。
- [ ] 登录天池平台，完成实名认证。
- [ ] 完成阿里云大学生认证。
- [ ] 在比赛页面选择赛道并点击「立即报名」。
- [ ] 确定个人参赛或 1–3 人组队；组队时确认每位成员均完成认证。
- [ ] 记录报名成功页面、队伍信息和所用账号（截图或文字）。
- [ ] 通过 <https://university.aliyun.com/action/qoder> 领取 Qoder CN 一个月免费权益。
- [ ] 记录作品开发所用的 Qoder 账号。

## 二、选题与开发

- [ ] 确定赛道和一句话作品方向：谁在什么场景下解决什么问题。
- [ ] 确认作品原创，未搬运他人作品。
- [ ] 确定技术栈和数据来源；需要外部数据时确认授权与隐私要求。
- [ ] 在 `src/` 中实现作品，保持可本地运行。
- [ ] 保留用 Qoder 开发的过程证据：关键提示、生成结果、人工修改和迭代截图。
- [ ] 准备 3–5 步以内的使用说明，确保评委可直接上手。

## 三、部署与验收

- [ ] 使用 Qoder Sites 完成部署。
- [ ] 将站点设置为公开访问。
- [ ] 用无痕窗口或未登录设备验证链接可打开、核心流程可用。
- [ ] 记录公网 URL、部署时间和部署截图。
- [ ] 检查移动端与桌面端基本可用性；确保没有密钥或隐私数据泄露。

## 四、作品帖发布

- [ ] 按 [作品帖草稿](../submission/forum-post.md) 补齐五个必填部分。
- [ ] 放入公网作品链接和所用 Qoder 账号。
- [ ] 加入开发与部署过程截图。
- [ ] 在天池赛题页论坛发布作品帖。
- [ ] 记录帖子 URL、发布时间和发布成功截图。
- [ ] 确认在 2026-11-30 18:00 前完成。

## 五、可选传播

- [ ] 在小红书、抖音、视频号或 X 发布作品案例，@qoder 官方账号。
- [ ] 标题或文案带上「2026 Qoder 高校创造力大赛」。
- [ ] 保留分享链接与截图，按官方要求领取社交传播奖。
