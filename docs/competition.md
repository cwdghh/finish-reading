# 2026 Qoder 高校创造力大赛：比赛资料

核对日期：2026-11-05  
官方页面：<https://tianchi.aliyun.com/competition/entrance/532536>

以下为项目内摘录，规则可能更新；报名与提交前以官方赛题页为准。

## 基本信息

- 名称：2026 Qoder 高校创造力大赛
- 主办方：Qoder
- 赞助方：NVIDIA
- 参赛对象：全国在校大学生，含本科生与硕博研究生（含港澳台），不限专业
- 参赛形式：1–3 人组队；可个人参赛
- 提交份数：不限；每个团队限获一项现金奖项，取最高分作品
- 核心任务：用 Qoder 开发一个完整项目，部署到 Qoder Sites 并开放公网访问，在截止前于天池赛题页论坛发布作品介绍帖

## 作品要求

- 必须使用 Qoder 完成：开发与部署均由 Qoder 完成，并在作品帖中说明使用过程。
- 必须原创：不得抄袭或搬运他人作品。
- 内容需完整呈现过程与结果：建议多用截图增强可信度。
- 符合活动主题、社区内容规范与相关法律法规。
- 作品应在活动规定时间内创作并发布。
- 资格：所有参赛成员须在初赛截止前完成天池平台实名认证和阿里云大学生认证，否则取消获奖资格。

## 论坛作品帖要求

帖子必须包含：

1. **作品链接**：Qoder Sites 部署后设置为公开访问的地址，评委点开即可访问。原则上不接受本地文件、压缩包。
2. **作品介绍**，至少包含五个部分：
   - 自我介绍
   - 作品是什么（一句话说清谁在什么场景下使用）
   - 为什么做（问题或想法的来源）
   - 怎么用（5 步以内，评委照着能自己打开用起来）
   - 用 Qoder 做出来的过程（哪几步交给它、你改了什么，尽量多包含截图凭证）
3. **（可选）分享链接**：小红书、抖音、视频号等分享帖或视频链接；标题需带上「2026 Qoder 高校创造力大赛」。

合格提交的判定：作品链接为 Qoder 部署的公网地址且能打开 + 作品介绍各部分齐全 + 填写所用 Qoder 账号。

## 参赛步骤

1. 在天池平台完成报名和组队；完成实名认证和阿里云大学生认证。
2. 通过 <https://university.aliyun.com/action/qoder> 完成学生认证，领取 Qoder CN 一个月免费使用权益。
3. 用 Qoder 开发，完成 Qoder Sites 公网部署，并在天池赛题页论坛发布作品介绍。

## 常见问题

- 不会写代码可以参加：三个赛道都收非代码作品，只要用 Qoder 做成可访问的站点页面。
- 只有想法不够：必须用 Qoder 部署到公网，别人点开就能用。
- 组队非强制：1–3 人均可；证书署名全体队员，奖金按队伍发放。
- 可提交多份作品，但每队限获一项奖。
